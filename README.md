# Magi Wigs – Custom Order Website

אתר תדמית וטופס הזמנה לפאות משיער אירופי בהתאמה אישית.

## תכונות
- עמוד נחיתה מודרני ורספונסיבי בעברית.
- הסבר על הזמנה ישירה ללא פערי תיווך.
- הדגשת מחיר התחלתי של €1,000 והזמנה ללא התחייבות.
- טופס רב־שלבי לבחירת כל פרטי הפאה.
- סיכום הזמנה ושליחה ישירה לוואטסאפ.

## הרצה מקומית
אפשר לפתוח את `index.html` ישירות בדפדפן, או להריץ:

```bash
python -m http.server 3000
```

ואז לפתוח: `http://localhost:3000`

## פריסה
האתר מתאים לפריסה חינמית ב־Vercel, Netlify או GitHub Pages.
